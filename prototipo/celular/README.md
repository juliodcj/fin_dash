# Mockup da tela Carteira no celular

A tela Carteira como está hoje no app (Manrope, fundo creme, azul, CDI em laranja, cores por classe). Só os blocos **Rentabilidade** e **Alocação** usam os elementos do [EasyUI](https://easyui.site/), com as cores do app:

- **Rentabilidade:** seletor de período com pill que desliza, números que rolam, gráfico de área com transição entre períodos e valores ao arrastar, % do CDI com barra até 100% e "Mais indicadores" que desdobra.
- **Alocação:** rosca por classe, barra de cada classe com a marca da meta, toque para destacar e aviso de onde pôr o próximo aporte.

Abra `index.html` no navegador. Em telas largas aparece dentro de uma moldura de celular; no celular ocupa a tela toda. Os números são de exemplo.
